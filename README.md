# Gen AI Academy feedback

Feedback for [Gen AI Academy](https://gen-ai-academy-sigma.vercel.app/), a free course on generative and agentic AI.

[Open an issue](../../issues/new/choose) to:

- **Report a content error**: a fact is wrong or out of date, an explanation is unclear, or a question has the wrong answer.
- **Report a site bug**: a page, button, diagram or the Playground doesn't work as expected.
- **Suggest a feature or topic**: an idea that would make the site more useful, or a topic you'd like covered.

The links on each lesson and on the site's Feedback page open these forms with the page filled in for you.

Issues here are public. Please don't paste API keys or personal details.
